# Security policy

## Supported versions

Only the latest release and `main` receive security fixes.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Report it privately with GitHub's **Report a vulnerability** button
in the repository's **Security** tab (private vulnerability reporting). Include the affected file or workflow, the
impact and steps to reproduce.

The maintainer acknowledges a report as soon as possible and agrees with the reporter on a fix and a disclosure
date.

## Secrets

This repository never contains credentials. If you find one, report it as a vulnerability so it can be revoked.
