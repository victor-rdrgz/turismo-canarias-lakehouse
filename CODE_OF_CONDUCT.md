# Code of conduct

This project is a place for technical collaboration. Everyone taking part, in issues, pull requests and
discussions, is expected to:

- Be respectful and assume good faith.
- Give and accept constructive feedback about the work, not the person.
- Keep the discussion on topic and the content free of personal data, credentials and anything unlawful.

Harassment, discrimination, personal attacks and the publication of other people's private information are not
accepted.

## Enforcement

The maintainer may edit or remove comments, issues and pull requests that break this code, and block repeat
offenders. To report a problem, use GitHub's "Report content" option on the comment or contact the maintainer
through their GitHub profile.
